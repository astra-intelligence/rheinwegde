## AiBlocks

An open marketplace for reusable AI components: prompts, skills, subagents, MCP servers, CLAUDE.md configs, hooks, slash commands, Claude plugins, and LLMs. Works across ecosystems (Claude, GPT, Gemini, DeepSeek) and also searches the wider web for components not yet in the catalog.

![AiBlocks home page](/images/aiblocks.webp)

[Open AiBlocks](https://aiblocks-six.vercel.app/)

## PATH

A workflow engine for processes that can stop and start again. Workflows are JSON files: steps do the work, controllers route it, and workers decide how each step runs. A stopped run resumes without repeating finished work, and person-activity steps wait for a human to complete them. Includes a visual designer.

![PATH designer with workflow and run details](/images/path.webp)
